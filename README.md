## 📌 About the Project

**PathFolio** is a web prototype developed in 2026 as a technical demonstration of a product concept I had been exploring prior to my **DEN502 Entrepreneurship course at Seneca Polytechnic**.

The concept was later proposed and further explored as a DEN502 group entrepreneurship project.

> **Project Status:** DEN502 academic prototype completed in 2026. This repository is maintained for portfolio demonstration and technical reference.

## 💻 About This Repository

This repository contains the **front-end prototype only**, built using HTML, CSS, and JavaScript.

The web prototype contained in this repository was **designed, developed, and implemented by Amany Omar**.

The broader DEN502 business planning, research, presentation, and other academic deliverables were completed collaboratively by the course project team and are **not contained in this repository**.
