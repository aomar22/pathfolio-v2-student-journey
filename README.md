## 💻 About This Repository

This repository contains the **front-end web prototype only**, built with HTML, CSS, and JavaScript.

The prototype was **designed, developed, and implemented by Amany Omar**, with input and feedback from the project team during the design and review process.

The broader business planning, research, presentations, and other DEN502 academic deliverables were completed collaboratively by the project team and are not contained in this repository.
